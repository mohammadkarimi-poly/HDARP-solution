# HDARP Solutions

This repository contains solution results for instances of the **Heterogeneous Dial-a-Ride Problem (HDARP)**.

## Description

The results reported in this repository are related to the benchmark instances introduced by [Malheiros et al. (2021)](https://doi.org/10.1016/j.cor.2020.105196) for the **Multi-Depot Heterogeneous Dial-a-Ride Problem (MDHDARP)**.

In the original problem setting, multiple depots are considered. However, in this repository, the MDHDARP instances are transformed into a **single-depot heterogeneous dial-a-ride problem** by assuming a common depot located at coordinates **(0, 0)**.

Therefore, the provided solutions correspond to the resulting **single-depot HDARP** version of the original MDHDARP benchmark instances.

The original MDHDARP benchmark instances proposed by Malheiros et al. (2021) are available in their GitHub repository: [Instances-MDHDARP](https://github.com/igormalheiros/Instances-MDHDARP).

## Source of Results

The solutions provided in this repository were obtained in the paper titled: **“A Variable Neighborhood Search Algorithm for a Very Large-Scale Practical Dial-a-Ride Problem”** by **Mohammad Karimi, Guy Desaulniers, and Michel Gendreau**, prepared for the journal **Computers & Operations Research**.
